Ohm's Law and Power Calculator

What it does

The Ohm's Law and Power Calculator is a Python program that calculates voltage, current, resistance, and electrical power using Ohm's Law formulas.

It allows users to select what they want to calculate, enter the required values, and receive accurate answers with the correct electrical units.

How to run it

1. Install Python 3 on your computer or Android phone.
2. Open the project folder.
3. Run the Python file using:

python ohms_law.py

My own twist

I added a calculation history feature that stores previous calculations during the program session.

This allows users to review their previous answers without performing the calculations again.

I also included input validation to prevent invalid entries and division-by-zero errors.
